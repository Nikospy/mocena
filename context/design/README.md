# Wygląd mOceny

Przyjęty przez autora 22.11.2026 („wygląd A”). mOcena wygląda jak kolejna usługa z rodziny mObywatel: spokojne tło, białe powierzchnie, kobalt jako jedyny akcent.

- `public/rodzina.css`: tokeny (kolory, odstępy, typografia, font Open Sans z `public/fonts/`, licencja OFL).
- `public/style.css`: komponenty i układ (nawigacja, karty, pola, pigułki przepisów).
- `mockups/notatka.html`, `mockups/ocena.html`, `mockups/os-czasu.html`: wzorce układu i zachowania. Otwierasz je w przeglądarce prosto z dysku.

## Trzy głosy

- **Człowiek:** biała karta z sygnaturą autora.
- **Reguła:** niebieska powierzchnia z ciągłą obwódką i pigułką przepisu. Znak „§” tylko przy paragrafie rozporządzenia, przy artykule ustawy bez znaku.
- **Podpowiedź:** obwódka przerywana i widoczne odrzucenie.

Ekrany biorą klasy i tokeny stąd. Własnych kolorów, rozmiarów i cieni nie dodajesz.
